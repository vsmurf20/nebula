# Espacio para Juego 10

Cuando tengas el juego listo, sube aquí su archivo HTML y llámalo **index.html**.

Después, edita el objeto correspondiente a **Juego 10** en el archivo raíz `games.js`: cambia el título, descripción, género, icono, portada y estado a `Disponible`.

La ruta ya está preparada: `games/juego-10/index.html`.
