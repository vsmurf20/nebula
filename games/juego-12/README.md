# Espacio para Juego 12

Después, edita el objeto correspondiente a **Juego 12** en el archivo raíz `games.js`: cambia el título, descripción, género, icono, portada y estado a `Disponible`.

La ruta ya está preparada: `games/juego-12/index.html`.
